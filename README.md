# GitHub 中文项目集合

本仓库用于保存开源项目的原始源码快照及中文说明文档。各项目的来源、作者、上游版本和许可证信息以项目目录内的 `SOURCE.md` 为准。

## 整理原则

- 不翻译、不修改程序源代码。
- 仅整理项目介绍、功能、使用、安装、部署、Docker、配置参数和常见问题。
- 保留原项目许可证、版权声明和明确的上游来源记录。
- 中文文档不声称对原项目拥有原创权。
